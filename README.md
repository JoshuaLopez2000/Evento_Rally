# Evento Rally 🎮

**Proyecto hecho en Unity (2022.3.5f1) con Vuforia/QCAR, desarrollado como participación en el Rally de Programación de la Facultad de Ingeniería UNAM (Evento 45).**

La app combina realidad aumentada, animaciones y contenido configurado mediante archivos JSON externos.

## 🛠 Tecnologías

- **Motor:** Unity `2022.3.5f1` (Universal Render Pipeline)
- **Realidad aumentada:** Vuforia / QCAR
- **Configuración:** parámetros de la experiencia definidos en JSON (`ConfigAppJson.json`, `JsonConfig.json`, carpeta `app_config`)

## 📂 Estructura

```text
Assets/
├── Animations/   # Animaciones de UI y contenido
├── Editor/       # Utilidades de editor
├── Fonts/        # Tipografías
├── Imagenes/     # Arte 2D y targets de AR
├── Resources/    # Recursos cargados en runtime
├── Scenes/       # Escenas principales
├── Script/       # Lógica C#
└── TextMesh Pro/ # Text rendering
```

## 🚀 Cómo ejecutarlo

1. Clona el repositorio.
2. Abre la carpeta en **Unity Hub** con Unity `2022.3.5f1`.
3. Abre la escena principal en `Assets/Scenes/`.
4. Acepta la activación de **XR/Vuforia** si Unity lo solicita.
5. Entra al Play Mode.
